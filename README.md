# Сад Лучей · Garden of Rays

Браузерная головоломка-сад для Яндекс Игр. Один HTML-билд, без сборки и внешних
библиотек: `index.html` + `assets/`.

**Играть:** откройте `index.html` или GitHub Pages этого репозитория.

## Что внутри

- 120 сюжетных уровней: 40 исходных уровней и 80 проверяемых новых головоломок;
- 12 тематических глав, постепенное усложнение и отдельный бесконечный режим задач;
- рисованная canvas-сцена, анимации, частицы, звук через WebAudio;
- русский и английский языки;
- сохранение прогресса в `localStorage`;
- поддержка Яндекс Games SDK: `LoadingAPI.ready()`, `GameplayAPI`,
  реклама, лидерборды. Если SDK недоступен (как на GitHub Pages), игра
  работает в локальном режиме и не падает.
- отдельная концепция новой игры для следующей сессии: [«Тёплый контур»](./NEW_GAME_IDEA_RU.md);
- англоязычный расширенный бриф: [EMBERSHIFT](./EMBERSHIFT_GAME_PROMPT.md).

## Управление

- мышь/палец: выбрать и повернуть луч;
- кнопки интерфейса: подсказка, звук, язык, меню;
- `Esc` — пауза/меню (в браузере).

## Второй прототип

В `echo-station/` лежит «Echo Station» — пиксельный action-roguelite из
сессии `Astra_Game`. Это отдельный однофайловый прототип: WASD/стрелки,
Space — рывок, автоматическая стрельба; на телефоне — джойстик и кнопка рывка.
Он не использует Yandex SDK.

## Локальный запуск

```powershell
cd G:\sessions\astra-game-site
npx --yes serve .
```

Или просто откройте `index.html` в браузере. Для проверки SDK нужен HTTPS и
контекст Яндекс Игр; локально SDK не загружается.

## Структура

```text
astra-game-site/
├── index.html                    # Сад Лучей
├── assets/                       # JS, CSS, шрифты и уровни
├── tools/extend-levels.mjs       # воспроизводимая генерация ещё 80 уровней
├── tools/test-campaign.mjs       # проверка уровня кампании и режима задач
├── NEW_GAME_IDEA_RU.md           # идея и задание для новой игры
├── EMBERSHIFT_GAME_PROMPT.md     # расширенный англоязычный бриф новой игры
├── echo-station/                 # отдельный прототип Echo Station
├── .nojekyll           # GitHub Pages: не прогонять через Jekyll
└── README.md
```

## Проверка кампании

```powershell
node tools/extend-levels.mjs
node tools/test-campaign.mjs
```

Проверка кампании подтверждает, что исходные 40 уровней не менялись, новые
80 уровней решаются встроенным решателем, в каждой из 12 глав по 10 задач, а
бесконечный режим воспроизводит одинаковую головоломку для одинакового seed.

## Публикация на Яндекс Играх

1. Соберите zip из `index.html` и `assets/` (без `echo-station/`, README и
   `.nojekyll`).
2. Загрузите zip в консоль разработчика Яндекс Игр.
3. Укажите иконку, обложку и скриншоты из `promo/` исходного проекта
   `garden-of-rays`.
4. Проверьте, что SDK загружается по HTTPS и `LoadingAPI.ready()` вызывается
   после инициализации.
